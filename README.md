# 🏥 Health Checkup Program

A comprehensive web-based health assessment and monitoring system built with Streamlit. This application provides users with tools to track their health metrics, receive personalized recommendations, and access evidence-based health guidelines.

## ✨ Features

### 📋 Health Checkup
- **Comprehensive Assessment Form** including:
  - Personal Information (name, age, gender)
  - Physical Measurements (height, weight, BMI)
  - Vital Signs (blood pressure, heart rate, temperature)
  - Lifestyle Habits (sleep, exercise, water intake)
  - Health Conditions (diabetes, hypertension, asthma, etc.)
  - Lifestyle Factors (smoking, alcohol, stress level)

### 📊 Health Dashboard
- Visual overview of latest health metrics
- Lifestyle metrics tracking
- Complete checkup history with data visualization
- Real-time health status indicators

### 📄 Health Reports
- **Summary Report**: Comprehensive health overview
- **BMI Report**: Body mass index analysis and recommendations
- **Vitals Report**: Blood pressure, heart rate, temperature analysis
- **Lifestyle Report**: Sleep, exercise, hydration, and stress assessment
- **Download Reports**: Export health reports as text files

### 📚 Health Guidelines
- **Nutrition**: Balanced diet recommendations and food guidelines
- **Exercise**: WHO-recommended physical activity guidelines
- **Sleep**: Sleep hygiene tips and recommended duration
- **Stress Management**: Techniques for reducing stress and anxiety
- **Disease Prevention**: Strategies for preventing common health conditions

### 💡 Personalized Recommendations
- Automatic health assessment based on checkup data
- Tailored recommendations for improvement
- Real-time health status feedback

## 🚀 Getting Started

### Prerequisites
- Python 3.7 or higher
- pip (Python package manager)

### Installation

1. **Clone the repository** (if not already cloned)
```bash
git clone https://github.com/hariomgupta2596-source/Health_checkup_Program.git
cd Health_checkup_Program
```

2. **Create a virtual environment** (recommended)
```bash
python -m venv venv
# On Windows
venv\Scripts\activate
# On macOS/Linux
source venv/bin/activate
```

3. **Install dependencies**
```bash
pip install -r requirements.txt
```

### Usage

Run the Streamlit app:
```bash
streamlit run streamlit_app.py
```

The application will open in your default web browser at `http://localhost:8501`
